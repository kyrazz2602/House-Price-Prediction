# House-Price-Prediction


![Python](https://img.shields.io/badge/Python-3.13%2B-blue)
![Scikit-Learn](https://img.shields.io/badge/Scikit--Learn-1.6.0-green)

Aplikasi web sederhana untuk memprediksi harga rumah menggunakan model Machine Learning (Ridge Regression).

## Deskripsi
Aplikasi ini memungkinkan pengguna untuk memprediksi harga rumah berdasarkan beberapa parameter:
- Lokasi
- Jumlah kamar tidur (BHK)
- Jumlah Bathroom
- Total luas (sqft)

## Teknologi yang Digunakan
- Python
- Flask
- Pandas
- NumPy
- Jupyter Notebook
- Bootstrap
- JavaScript
- Scikit-learn (untuk model Ridge Regression)
- HTML/CSS (untuk antarmuka web)

## Cara Instalasi
1. Clone repository ini
2. Install the required dependencies:

   ```shell
   pip install -r requirements.txt
   
3. Run the Flask application:
   
   ```shell
   python app.py

4. Open your web browser and visit http://localhost:5000 to use the web application for house price predictions.
